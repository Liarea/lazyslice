# T-0303 · tools/names regenerates the masker's name lists from the 2020 Census top-1000 files (public domain), checked in CI

## Goal

Corpus decided 2026-09-22 (research memo in the orchestrator's record): the U.S. Census Bureau's 2020 Census names release, https://www.census.gov/topics/population/genealogy/data/2020_names.html, files Names2020_FirstNames_Sex_Top1000.xlsx and Names2020_LastNames_RaceHispanic_Top1000.xlsx under https://www2.census.gov/topics/genealogy/2020surnames/ (works of the U.S. Government, 17 U.S.C. 105; the Bureau asks for citation, https://www.census.gov/about/policies/citation.html). Fetch both today and record sha256 and the column headers as found in tools/names/README.md with the one-time xlsx-to-csv command. Commit tools/names/census2020_first_names_sex_top1000.csv (name,sex,rank,count) and census2020_last_names_top1000.csv (name,rank,count): read ONLY the name, sex, rank and count columns; never read or embed the race or Hispanic-origin proportion columns. Write a Go generator, go run ./tools/names (root module, like tools/docgen), with flags -given-per-sex 500 -surnames 1000: union the top-500 male and top-500 female given names and dedupe, take all 1000 surnames, lowercase, drop and count any token outside ^[a-z]+$ (assert zero drops), assert length <= mask's maxFit (32) and no duplicates within a list, write mask/words_corpus.go alphabetically with the '// Code generated by tools/names; DO NOT EDIT.' header holding censusGivenWords and censusSurnameWords as backtick constants in words.go's shape; go run ./tools/names -check regenerates to a buffer and exits 1 on drift; Makefile names and names-check targets, names-check wired into make check and the CI docs job (offline, nothing downloaded at build time). THIRD_PARTY_NOTICES.md gains a section after the names.txt one in the same shape (files, licence basis citing the statute, URLs, date, sha256s, the cut and the merged counts, the Bureau's citation line). Do NOT wire the constants into any masker in this task: the lists become the masker's vocabulary in the follow-up task, after ADR-015's verify half lands. A mask test pins the counts and the character class so a silent regeneration with a different cut fails loudly.

## Acceptance

make check green with names-check; go run ./tools/names -check exit 0 on the committed file; the notices section reproducible by a stranger; no masker output changes in this task.
