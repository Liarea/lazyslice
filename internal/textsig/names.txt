# The name dictionary (ARCHITECTURE.md §4 "Signals").
#
# One name per line, lower case, in two sections. Blank lines and lines
# beginning with "#" are ignored.
#
# It was English only until the 2026-09-15 red team, and the limit was stated
# rather than an oversight: ARCHITECTURE.md §14 put the multilingual
# dictionaries in phase 5. The red team is what phase 5 is, and it showed the
# cost of the deferral in one run — a `klienci` table whose `nazwisko`,
# `imie` and `komorka` columns held Polish names and numbers reached the
# target verbatim under exit 0, because neither net had a rule for the column
# *name* nor a dictionary entry for the *value*. THREAT_MODEL.md T1 records
# what is still missing.
#
# What was added is the given/surname stock of the languages the attacks used
# and of the largest name populations beside them: Polish, Italian, Dutch,
# Turkish, Icelandic, Igbo and Yoruba, Kikuyu and Luo, Swedish, Finnish,
# German, French, Spanish and Portuguese, Arabic, Indian, Japanese, Korean,
# Vietnamese, Russian, Greek and Chinese. It is still a dictionary of common
# names and not a census, for the reason below.
#
# The list is part of the masking mapping in the sense that
# Classification.Fingerprint covers the rule-pack version, so a name added here
# can move a column's category and is announced as "classification changed"
# rather than shipping silently (ARCHITECTURE.md §5 "Determinism scope").
#
# It is deliberately a dictionary of common names and not a census: a longer
# list raises recall on prose and lowers precision on ordinary English words,
# and the words below were checked against the failure that matters — a column
# of ordinary English text classified as person_name because every other word
# is also a first name. Two rules follow from that and hold for every entry
# added since: **no name shorter than three characters** (a two-letter value is
# an ISO code far more often than it is a person, and `TwoLetterCode` is the
# signal for it), and **no name that is also an ordinary English word** unless
# the list already carried it — which is why Park, Can and Long are not here
# though each is a common surname somewhere.
