# docs/

Decisions, plans, and generated references. `adr/` holds the ADRs;
`BUILD_PLAN.md`, `OPERATING_MODEL.md`, `RUNBOOK.md` are hand-written;
`FLAGS.md`, `ERRORS.md`, `KEYBINDINGS.md` (not yet generated) are `tools/`
output and must never be hand-edited; `prompting/` holds per-model cheat
sheets. `launch/` is an empty directory left over from the phase 0 scaffold;
nothing has been decided about what goes in it, and no document in this
repository assigns it a purpose. Do not write one into a CLAUDE.md — either
delete the directory or land an ADR that says what it is for.

**Contract.** `docs/adr/README.md` is this directory's own format spec for
ADRs (Status/Context/Options/Decision/Consequences/Reversal condition,
numbered `NNN-short-name.md`) — follow it rather than inventing a shape.
ARCHITECTURE.md and THREAT_MODEL.md live at the repo root, not here, and are
the source of truth `FLAGS.md`/`ERRORS.md` are generated from (§8, §7 of
ARCHITECTURE.md; `internal/event/catalogue.yml`).

**Rules.**
- Never edit an accepted ADR (root CLAUDE.md). To change a decision, add a new
  ADR (Status: `proposed`, then `accepted, YYYY-MM-DD` when its gate closes)
  and change only the old ADR's Status line to
  `superseded by ADR-NNN, YYYY-MM-DD`; nothing else in the old file changes.
- Every ADR needs a stated reversal condition — an observable trigger, not a
  feeling (`docs/adr/README.md`); Gate 2 checks this.
- `FLAGS.md`, `ERRORS.md`, `KEYBINDINGS.md` are generated by `tools/docgen`
  from ARCHITECTURE.md §8, the event catalogue, and keybindings respectively;
  CI fails on drift. Fix the source, regenerate, never hand-patch the output.
  The same holds for the block between the `docgen:flags` markers in the root
  `README.md` (T-0259): which flags appear there is a curated list in
  `tools/docgen/readme.go`, and the rows themselves come from `--help`.
- `docs/READ_ONLY_ROLE.md` is referenced from the decision header
  (ARCHITECTURE.md §9) but must never be *the* answer to a confusing first
  run — root CLAUDE.md: "documentation is never the fix for a confusing first
  run."

**Test.** No test suite of its own; `docs/adr/README.md`'s index table must
list every file in `adr/`, and CI's docs-drift job (once `tools/docgen` exists)
checks the generated files.

**Never:** edit an accepted ADR's Decision/Consequences sections; hand-edit a
generated file; add a doc as the fix for a confusing default instead of
changing the default.
