# tools/

Build-time and maintenance tools — every one generates, checks or automates
something the product itself does not run at runtime, so nothing here is
imported by `cmd/lazyslice` or `internal/`. `docgen/` regenerates
`docs/FLAGS.md`, `docs/KEYBINDINGS.md`, `docs/ERRORS.md` and README.md's
flag table from the tree's own registered surfaces (`make docs`,
`make docs-check`). `egress/` is the network-egress test's harness
(`make egress`, THREAT_MODEL.md T4). `release/` holds `tag.sh`
(`make tag`). `relnotes/` renders release notes from commit history
(`make relnotes`). `tracker.py` (plus `test_tracker.py`) is the tracker CLI
root CLAUDE.md's "Tracker and commits" section describes; `make tools-test`
runs its suite. `names/` is described below.

## `names/` — the 2020 Census name corpus generator (T-0303)

`go run ./tools/names` (`make names`) regenerates `mask/words_corpus.go`
from the two CSVs `tools/names/` itself carries —
`census2020_first_names_sex_top1000.csv` and
`census2020_last_names_top1000.csv`, extracted once by hand from the U.S.
Census Bureau's 2020 Census top-1000 name files. `tools/names/README.md` is
the full record: source URLs, each file's sha256, its column headers as
found, the one-time xlsx-to-csv extraction command, and what the generator
does with the result. `go run ./tools/names -check`
(`make names-check`, wired into `make check` and into
`.github/workflows/ci.yml`'s `docs` job) regenerates into memory instead of
writing and exits 1 if the committed `mask/words_corpus.go` differs.

**Offline by design**, the same way `docgen` is: both CSVs are checked in,
so neither `names` nor `names-check` downloads anything, at build, test or
CI time. Re-fetching the source `.xlsx` files is a deliberate, occasional,
by-hand step documented in `tools/names/README.md` — not something this
tool, `make check`, or CI ever does on its own.

**`mask/words_corpus.go` is generated output**, carrying the header
`// Code generated by tools/names; DO NOT EDIT.` (the docs/CLAUDE.md rule
against hand-editing a generated file, restated here because this one is
not under `docs/`). Its two constants, `censusGivenWords` and
`censusSurnameWords`, are not read by any masker as of this task — see
`mask/CLAUDE.md`'s own note on `words_corpus.go` for why, and tracker
T-0304, which wires them in.

**Test.** `cd tools/names && go test ./...` — `main_test.go`'s `TestNoDrops`
runs the real filter over the two checked-in CSVs and asserts it drops
nothing, so a future re-fetch that introduces a name outside `^[a-z]+$`
fails here rather than silently shrinking the corpus.
`mask/words_corpus_test.go` is the other half: it pins the generated
counts, character class and length bound on the committed output itself.

**Never:** hand-edit `mask/words_corpus.go`; add a network call to `names`
or `names-check`; read the surnames file's race or Hispanic-origin
proportion columns (`tools/names/README.md` says why, and
`THIRD_PARTY_NOTICES.md`'s own section for this corpus says so too).
